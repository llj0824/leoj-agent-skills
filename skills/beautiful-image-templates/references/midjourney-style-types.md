## Suggested Style Families for Expert Interview Visuals

These are stronger than generic card grids:

### 1. Scientific Handout

Use when the interview explains mechanisms.

Prompt ingredients:
- analytic drawing
- clean classroom handout
- causal arrows
- labeled mechanisms
- white background
- no decorative clutter

### 2. Philosophical Field Map

Use when the interview is about tensions and hidden assumptions.

Prompt ingredients:
- monochrome blueprint
- sparse nodes
- tension axes
- marginal annotations
- paper texture
- fine linework

### 3. Forensic Evidence Board

Use when the interview tests claims against examples.

Prompt ingredients:
- old photograph
- annotated evidence board
- pins, threads, clipped quotes
- muted color
- no sensationalism

### 4. Museum Wall Chart

Use when the interview has lineage and branching ideas.

Prompt ingredients:
- timeline wall
- epistemic lineage
- archival labels
- restrained serif typography
- warm gallery lighting

### 5. Architectural Section

Use when the interview has layered concepts.

Prompt ingredients:
- architectural blueprint
- cross-section
- foundations, structure, circulation
- precise labels
- matte paper

### 6. Systems Biology Diagram

Use when ideas act like feedback loops.

Prompt ingredients:
- molecular / cellular diagram style
- feedback loops
- input, mediator, output
- flat scientific icon system
- high legibility

### 7. Minimal Ink Constellation

Use when the interview is associative and idea-dense.

Prompt ingredients:
- Japanese ink
- constellation map
- central thesis and satellite ideas
- generous blank space
- quiet annotations

### 8. Risograph Knowledge Poster

Use when the image should feel editorial and alive without becoming glossy.

Prompt ingredients:
- risograph
- two-color overprint
- abstract blocks
- imperfect registration
- clear text hierarchy

### 9. Decision Atlas

Use when readers need to decide where to skim, dive, or skip without being told.

Prompt ingredients:
- map legend
- terrain regions
- route options
- signal markers
- neutral descriptive labels
