# Systems Biology Diagram

Use when ideas behave like a living system: inputs, mediators, feedback loops, inhibition, amplification, and outputs.

## Visual System

- Structure: pathway diagram with feedback loops
- Composition: input nodes on the left, mediators in the center, outputs on the right, feedback arcs
- Style terms: molecular, cellular diagram, flat scientific icon system, high legibility, infographic drawing
- Palette: clean scientific colors, limited accents for activation/inhibition
- Text policy: short pathway labels; use symbols for positive and negative feedback

## Prompt Template

```text
Create a systems biology diagram image about {subject}. Represent the ideas as a clean pathway map with inputs, mediators, outputs, feedback loops, amplification, and inhibition. Use molecular diagram style, flat scientific icon system, high legibility, analytic drawing, controlled color accents, white background, precise arrows. No medical gore, no decorative molecules, no unreadable labels, no glossy 3D cells.
```

## Good Fit

- Feedback-heavy systems
- Psychology, markets, media, organizations, biology, AI alignment
- Explaining interaction rather than chronology
