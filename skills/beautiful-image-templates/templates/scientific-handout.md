# Scientific Handout

Use when the subject is best understood as a mechanism, causal chain, or set of interacting parts.

## Visual System

- Structure: labeled mechanism diagram
- Composition: clean white page, 3-5 grouped zones, arrows only where causality is real
- Style terms: analytic drawing, infographic drawing, diagrammatic drawing, high key lighting, white background, paper
- Palette: restrained black/gray linework with one accent color
- Text policy: short labels only; add exact copy in a deterministic overlay when needed

## Prompt Template

```text
Create a scientific handout image about {subject}. Show {information_structure} as a clear labeled mechanism diagram with 3-5 grouped zones, causal arrows, and generous white space. Use analytic drawing, infographic drawing, diagrammatic drawing, crisp black linework, subtle accent color, high key lighting, matte paper texture, top-down educational composition. Keep labels short and legible. No decorative clutter, no fake UI, no dense paragraphs, no glossy 3D render.
```

## Good Fit

- Explaining how a concept works
- Mechanism-heavy interviews
- Research summaries where causality matters
