# Decision Atlas

Use when the image should help readers decide where to dive, skim, or skip without explicitly commanding them.

## Visual System

- Structure: atlas map with terrain regions, route options, and signal markers
- Composition: top view, one legend, named regions, path alternatives, neutral symbols
- Style terms: top view, map legend, matte paper, low-purity color, wide view
- Palette: muted cartographic colors with one signal accent
- Text policy: region and marker labels only; timestamps or exact labels should be overlaid after generation

## Prompt Template

```text
Create a decision atlas image about {subject}. Represent the discussion as a top-view terrain map with named conceptual regions, route options, signal markers, and a compact legend. Use matte paper texture, low-purity cartographic color, precise linework, wide view, quiet editorial design. The image should reveal where the dense, foundational, speculative, and optional areas are, while letting the reader choose their own path. No tourist-map gimmicks, no arrows telling the reader what to do, no fake UI cards, no tiny unreadable text.
```

## Good Fit

- Long interviews or podcasts
- Reading maps
- Visual navigation where the viewer decides the path
